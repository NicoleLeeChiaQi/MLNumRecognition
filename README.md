## Getting Started
1) Install the required package
```bash
pip install torch torchvision numpy opencv-python scipy matplotlib scikit-learn seaborn pillow
```

2) Copy and paste the "train.py" code into Google Colab and run it

3) Download file named "best_mnist_cnn.pth" and place it back into VS Code

4) Run the following command in terminal
```bash
python evaluate.py
python canvas_gui.py
```

5) User can try to write a number on the pop out terminal
